💼 **경력**

- **대한민국 공군 — 공군지능정보체계관리단 AI신기술체계개발대 데이터플랫폼팀** (2025.10 – 2026.11)
  공군 내부 공개 파견 공고에 지원하여 서류 및 면접 전형을 통해 선발되어 부서 이동.
  주요 파이프라인 개발을 주도:
  - **Airwards 이미지 검색 파이프라인**: OpenSearch(BGE-M3 신경망 검색), vLLM, MinIO, Airflow를 활용한 RAG 기반 이미지 검색 서비스. Gemma 모델을 활용한 이미지 캡셔닝 파이프라인 구축 및 키워드 + kNN 하이브리드 검색 구현. 이후 지속적인 유지보수 수행 중.
  - **RAG 평가 파이프라인**: RAGAS, DeepEval(커스텀 G-Eval 메트릭), RAGChecker를 활용한 평가 프레임워크 설계 및 구현. Langfuse를 연동하고 GPT-OSS를 Judge 모델로 활용한 자동화 평가 환경 조성. 골든 데이터셋을 구축하고 지속적으로 추가.
  - **STT 군사 용어 오류 교정 파이프라인**: g2pk 음성 전사, hgtk 자모 분해를 활용해 한국어 음운 규칙(격음화, 경음화, 유음화, 모음 혼동 등)을 검증하는 치환 사전 생성 로직 개발.
  - **워드클라우드 대시보드 기능**: Langfuse 로그에서 키워드를 추출해 Canonical 방식으로 분류한 뒤 Airwards 대시보드로 전송, 실사용자 데이터·로그 시각화 지원.
